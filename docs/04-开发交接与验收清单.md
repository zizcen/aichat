# 开发交接与验收清单

本清单已按仓库 `v3.1.4` 的以下源码复核：`frontend/src/features/creative-console/creative-console-page.tsx`、`frontend/src/features/creative-console/creative-console-api.ts`、`backend/internal/transport/http/inference/handler.go`、`backend/internal/transport/http/inference/voice_handler.go`、`backend/internal/transport/http/media/handler.go`。复核日期：2026-08-24。

## 开发前必须确认

- [ ] 目标 VPS 的 grok2api 版本、Base URL、是否强制 HTTPS。
- [ ] 测试用 Client Key 及其模型白名单、RPM/并发/过期限制。
- [ ] `GET /v1/models` 是否增加 capability 元数据；若没有，确认 APK 内置映射方案。
- [ ] 目标部署启用的模型和能力：Responses、图片、视频、TTS、STT。
- [ ] 是否要求图片编辑、视频编辑/延长、录音、Realtime；这些不是 MVP 必需项。
- [ ] 是否允许公网媒体 URL；是否需要新增公共临时上传接口。
- [ ] 是否接受归档媒体 URL 的公开可访问语义；不要把 `/v1/media/images/{asset_id}` 或 `/v1/media/videos/{asset_id}` 当成 Key 保护接口。
- [ ] 应用包名、图标、最低 Android 版本、签名和发布渠道。

## P0 开发顺序

1. 连接配置、安全存储、健康检查和模型拉取。
2. Responses SSE 聊天、会话本地存储、停止/重试/编辑。
3. 图片生成和媒体保存/分享。
4. 视频生成、任务持久化和轮询。
5. TTS/STT 文件选择、播放和下载。
6. 真机验收、弱网和安全审计。

## 测试矩阵

| 模块 | 必测成功路径 | 必测异常 |
|---|---|---|
| 连接 | HTTPS、有效 Key、空模型列表 | URL 错、401、403、503、证书错误、超时 |
| 模型 | 白名单过滤、刷新、手动模型 | 空响应、重复 ID、坏 JSON |
| 聊天 | SSE 增量、非 SSE JSON、推理、工具、停止 | 空流、incomplete、failed、断网、429、切会话竞态 |
| 历史 | 新建、切换、删除、重启恢复、50 条上限 | 坏数据、超容量、切换 profile 串数据 |
| 图片 | URL、b64_json、1–4 张、比例/分辨率 | 非 JSON、媒体 404、超大结果、取消 |
| 视频 | pending→done、pending→failed、恢复轮询 | 4xx 不重试、5xx 退避、后台恢复、过期任务 |
| TTS | 原始音频、JSON Base64、播放/下载 | 不支持 voice、音频 MIME 缺失、超时 |
| STT | multipart、中文/英文、结果展示 | 文件类型/大小、401、上传中断、坏响应 |
| 安全 | Key 脱敏、清除、HTTPS | 日志/剪贴板/备份泄漏、跨域媒体 |

## 已知限制

当前上游创作台的视频本地文件选择依赖 `/api/admin/v1/media/inputs/upload`，这与“APK 只使用 URL + API Key”的边界冲突。开发者不能绕过权限调用该接口；应在 MVP 禁用本地视频/图片上传，或先修改 grok2api 增加公共临时上传接口并补充安全限制。

但公共视频接口自身接受 `image.url`、`reference_images[].url` 和 `video.url`，所以 APK 的 MVP 可以支持公网 URL，不需要调用 admin staging。任务完成后优先使用服务端返回的 `/v1/media/videos/{asset_id}`；若只有 `/v1/videos/{request_id}/content`，下载/播放请求必须附带 Bearer Key。
