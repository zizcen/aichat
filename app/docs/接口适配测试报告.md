# 接口适配测试报告（开发快照）

## 自动化覆盖

`src/shared/api/` 和本地状态层当前有 6 个 Vitest 文件、18 个测试：

- URL 规范化：去尾斜杠、拒绝 admin 路径、媒体路径与路径穿越。
- 媒体 URL 兼容：把旧版 loopback `http://127.0.0.1:8000/v1/media/images|videos/...` 改写到当前 Base URL，同时拒绝任意非媒体 HTTP 地址。
- Client：健康检查不带 Bearer、模型 JSON、图片 URL/base64、视频状态、Responses JSON、TTS 二进制/JSON、STT multipart boundary。
- Responses SSE：跨 chunk UTF-8、多行 `data:`、delta/reasoning/tool、completed/incomplete。
- 能力映射：服务端字段优先、已知模型 fallback、重复模型 ID 过滤。
- profile round-trip：对象格式迁移、Key 规范化、删除和 scope 隔离。
- 本地会话：50 条上限、scope 隔离、容量整理。

执行：

```powershell
cd app
node_modules/.bin/vitest run
```

当前结果：6 files / 18 tests passed。
