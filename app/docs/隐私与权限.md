# 隐私、权限与数据删除

## 网络

应用只向用户填写的 grok2api Base URL 发起请求，使用 `Authorization: Bearer`。不包含开发者自己的 Key，不调用第三方中转，也不调用管理端 `/api/admin/v1/*`。Release Android 壳关闭明文网络；开发态局域网 HTTP 仅用于本机调试。

## API Key

profile 元数据只保存 URL、随机 profile ID、Key 引用和 scope hash，不保存完整 Key。Android 使用自定义 Capacitor `SecureStore` 插件和 Android Keystore AES-GCM 加密；Web fallback 只把密文放在 localStorage，把解密密钥留在当前 sessionStorage，因此刷新后会要求重新输入。Key 不进入日志、剪贴板、会话标题、URL、Intent extras 或诊断信息。

## 本地数据

聊天会话按 `sha256(normalizedBaseUrl + "\\n" + apiKey)` 的 scope 隔离，最多 50 个会话、约 4 MiB。视频 request ID 和状态按同一 scope 保存。删除 profile 时可选择同时删除历史和媒体索引；不选择时只删除连接密钥和 profile 元数据。

## 系统权限

MVP 仅需要网络权限和系统文件选择器，不申请 `RECORD_AUDIO`。TTS 音频可播放、下载或分享；STT 文件在发送前检查 MIME 和 10 MiB 大小上限，以避免移动端桥接大对象造成内存峰值。录音和 Realtime WebSocket 属于后续版本，需要单独的权限与隐私说明。

归档图片/视频 URL 可能是服务端公开读取资源。分享前请确认内容和链接本身适合公开，不要把它当成 Key 保护资源。
